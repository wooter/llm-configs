# LLM Configs

Personal customizations and system prompts for various LLM platforms.

## Contents

- **ChatGPT Customization 1.md** - Custom instructions and settings for ChatGPT
- **ChatGPT Customization 2.md** - Additional ChatGPT customizations

## Usage

These configurations can be copied directly into your LLM platform's custom instructions or system prompt settings.

## Organization

Each file is named by platform and purpose. Configurations are stored as markdown for easy reading and version control.
